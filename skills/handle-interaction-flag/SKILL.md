# Handle an interaction flag

1. State the flagged pair and the effect in one or two simple sentences.
2. Stay calm. Do not frighten the user, and do not minimise the flag.
3. Do NOT tell the user to stop either medicine. Say: "Please talk to your doctor or pharmacist today before changing anything."
4. For CONTRADICTED or CONTRAINDICATED pairs, add that this should be checked as soon as possible.
5. If no flag was found, never say the medicines are "safe together". Say the small reference list found nothing and a pharmacist should confirm.
